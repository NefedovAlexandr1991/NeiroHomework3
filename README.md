## Запуск проекта

Из командной строки: streamlit run main.py

## Описание 3-х проверок сценария

1. Пустой ввод

Вывод сообщения об ошибке: Проверьте корректность введённых данных.

2. Слишком длинный ввод, более 50 символов

Вывод сообщения об ошибке: Проверьте корректность введённых данных.

3. Нормальный ввод

суп шурпа, 4 человека, список продуктов

Ответ:

Список продуктов:

Мясо (говядина или баранина) – 1 кг
Картофель – 800 г
Лук репчатый – 2 шт.
Морковь – 2 шт.
Помидоры свежие – 3 шт.
Болгарский перец – 1 шт.
Чеснок – 3 зубчика
Зелень (петрушка, укроп) – пучок
Лавровый лист – 2 шт.
Перец черный молотый – по вкусу
Соль – по вкусу
Масло растительное – для жарки
Вода – 2 литра
